The editor

A canvas that only does the things you actually need

No plugin sprawl, no canvas library, no learning curve. Drag a layer to move it, grab a corner to resize it, and tune the rest in one properties panel that behaves the same in the Template view and the Studio.

Shared brand assets

Drag-and-drop the background, key visual and logotype. Frames reference them by kind, never by copy — so a replacement propagates everywhere at once.

Branches, not duplicates

Create a branch empty or fork the current one — frames come with it, assets stay shared. Fork lineage is recorded, so you always know where a layout came from.

Layer control that stays put

Position, size, rotation, opacity and z-order; text content, size, weight, colour and alignment; rectangle fill and radius. Uniform scaling, with the artwork centroid pinned so nothing drifts on resize.

How it works

Shared below, divergent above

The brand sits underneath every branch. Layout sits on top of it. Change something in the shared layer and it lands everywhere; change something on a branch and it stays there.

1

Upload the core assets

Background, key visual and logotype — one active asset per kind, stored in your own bucket.

2

Build the template once

Place the assets, the headline and the supporting copy on each size. That layout is your starting point.

3

Fork a branch per client

The fork copies the frames and keeps the assets shared. Tune the layout for that client only.

4

Swap an asset, ship again

Replace the key visual and every branch picks it up. Export the frames you need at full resolution.

Export

What you place is what ships

Export renders the frame to a canvas at its full resolution using the same scaling model as the live preview — no re-layout, no surprise crops, no hand-checking against the design file.

Full-resolution PNG

The frame is drawn at its declared pixel size, straight out of the editor.

Parity with the preview

The renderer and the exporter share one scaling model, so the export matches the canvas.
