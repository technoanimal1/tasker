How it works

One template. The whole catalogue.

The layout isn’t drawn into any file — it’s data. Anchors, scales, the light band, the provider tab: stored once per aspect, applied to every game at render time.

01

Set the template once

Where the key visual sits, how large the logotype runs, where the light band falls — decided once, per aspect size, by a designer.

02

Drop in a game

Background, key visual, white logotype. Three layers per title — the template places them, and nothing is redrawn by hand.

03

Serve every cut

Portrait stacks, landscape splits key-visual-left and logo-right. A new size is one layout to set — not 6,000 files to redraw.

The anatomy

Six layers. Zero hand-drawing.

Tap the tile to pull it apart. Everything below the artwork — the band, the glow, the tab, the stroke — is the frame, and the frame is the same for all 6,000 games.

PRAGMATIC

Background

The game’s own scene, filling the frame at 120% so every cut stays covered.

Key visual

A clean cutout with its own transparent padding, anchored and scaled by the template — never stretched.

Light band

A seamless gradient in the game’s accent colour, eased in so there’s no visible edge.

Glow + bloom

A colour glow and a white overlay bloom lift the lower third, exactly like the renderer.

Logotype

The original game logotype, white where the art needs it — original branding, not typography.

Provider tab

The provider’s name on a tab in the frame colour, flush to the bottom edge.
