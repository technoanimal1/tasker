# thumbs.store — Design System Dashboard (MVP)

A scalable dashboard for producing per-client design deliverables from a shared
set of brand assets.

- **Core assets** (background, key visual, logotype) are imported once and shared.
- **Frames** are compositions built on those assets.
- **Branches** let frame designs diverge per client / product update without
  duplicating the core brand.

Work in progress — see commit history.
