# thumbs.store — teaser & launch copy kit

Voice rules: lowercase `thumbs.store`, short declarative sentences, operational
pain before product, numbers do the bragging ("10,000+", "60+", "one
template"), never "revolutionary/game-changing". One yellow claim per post —
the rest stays matter-of-fact. Every visual should be a real render, never a
mock-up, and say so.
